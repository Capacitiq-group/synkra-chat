# Canned responses and macros

## What's a canned response?

A saved reply template you can insert into a conversation instantly,
for anything you find yourself typing repeatedly. Create them under
Settings → Canned Responses, then trigger one while replying by typing
`/` followed by its shortcode.

## What's a macro?

A sequence of actions bundled together and run with one click — for
example, "send this reply, add this label, mark as resolved" as a
single action instead of three. Set these up under Settings → Macros.

## What's the difference between the two?

A canned response inserts text. A macro can insert text *and* perform
other actions (labeling, resolving, assigning) all at once. If you
just need a reusable reply, use a canned response; if you want a
whole repeatable workflow in one click, use a macro.

## Can I use variables in a canned response?

Yes — reference things like the contact's name so the inserted text
personalizes itself automatically rather than needing manual editing
every time.
